The three scripts for the three algorithms are separated into folders.
Lis_main_x.py runs the simulation and is functionally the same for all cases.
LiS_functions_x.py contains the residual. The particle flux portion of this 
residual is what distinguishes each algorithm and the equations are the 
same as the ones in the letter.
